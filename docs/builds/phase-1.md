# Phase 1 build notes: the town and day zero world

Pushed 2026-10-31 in three commits on main:
- `177d5fe` "Phase 1: V2 day-zero content drop" (7 files)
- `42432fe` "Phase 1: content drop part 2 and town data" (8 files)
- `bf6a59f` "Phase 1: world server, web town, and tests" (12 files)

27 files total. The single push was split into three because the push tool cannot take all 138KB in one call.

## What was built
- Content merge: all 11 V2 day-zero JSONs installed into `content/`. The 4 superseded V1 files (buildings, items, events, plants) were archived to `archive/phase0/` with a README; V1-only files (needs, foods, genres, emotion_rules, unlocks) stay for the Phase 0 brain. Two event-spawned objects had no definitions in the drop, so `stray_balloon` and `old_newspaper` were added to objects.json (27 objects now). `content/README.md` documents the merge and every tracked open item.
- `content/layout.json`: generated by `world/build_layout.py` from the town blueprint. Meters, x east / z south / y up, bounds 150x110. 14 buildings, 27 placed objects, 29 waypoints with 36 edges, all reachable from the park-gate spawn.
- `content/tuning.json`: clock, need drains, feelings, decisions, learning, memory, bonds, social, and the hosted-model cap, all from the roadmap appendix.
- `content/animations.json`: 31 named animations.
- `world/src/worker.js`: rewritten world server. Durable Object TownState with a 10s alarm tick, fixed WebSocket message format v1, endpoints /ws, /api/state, /api/layout, /api/observe, POST /api/act with the roadmap error set. Vending rules (free bar 6/day by ET date, fan-only slots refused, stock, wallet in cents). BFS pathfinding over layout waypoints. ET day/night from a real solar algorithm, moon phase, Jacksonville weather from Open-Meteo (no key, cached 30 min). Placeholder wander behavior; the Phase 2 sim and Phase 3 brain take over later.
- `world/public/`: three.js client rebuilt from layout.json. Buildings colored by state, striped sage-and-wine tent, wall view modes (up/cutaway/down), orbit and follow-Norn camera, day/night lighting and sky, lamps at night, rain particles and fog, placeholder Norn, HUD with ET clock, weather, moon, and wallet.
- Town blueprint reference image at `docs/town-blueprint.jpg`.

## Test results
- 43 pytest passed (`tests/test_content.py` rewritten for V2 schemas plus regression test that every event `spawns_object` resolves; new `tests/test_layout.py` with 7 layout tests).
- `world/smoke_test.mjs`: all checks passed (sun, moon, weather codes, pathfinding, ET date key). Worker.js syntax OK.

## Deploy notes
- Cloudflare Workers Builds deploys main automatically. The first build failed: the build command was `cd world && npm ci && npm run build` but there is no package.json (nothing to build). Fixed in the Cloudflare dashboard by setting the build command to `echo "no build step"`; the deploy command stays `cd world && npx wrangler deploy`.
- Verified live 2026-10-31: norntheclown.com serves, /api/state ticking, Norn walking main street.
